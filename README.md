# Stockslide

A minimal one-screen holdings tracker. Yellow fill rises with progress toward your dollar target. Live SNAP (or other) quote from Yahoo Finance; slider for what-if prices; NYSE open/closed badge; settings in a bottom sheet.

Defaults:

- SNAP × 130,000 shares
- Additional assets: $3,530,000
- Target: $5,000,000
- Yearly distribution rate: 4%

## Open locally

```bash
npx --yes serve .
```

Then open the printed URL (usually http://localhost:3000).
